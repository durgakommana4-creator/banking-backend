# Banking System Backend

A secure backend API for a banking system built using Node.js, Express, and MySQL.

## Features

- User signup and login
- JWT authentication
- Role-based access control
- Secure password hashing
- Create bank accounts
- View account details and balance
- Deposit money
- Withdraw money
- Transfer money
- View transaction history
- Admin dashboard
- Admin access to users, accounts, and transactions

## Technologies Used

- Node.js
- Express.js
- MySQL
- JWT
- bcryptjs
- dotenv

## How to Run

```bash
npm install
npm start
